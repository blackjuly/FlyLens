飞镜使用指南

从安装到开拍，
按你的现场来。

选择你要使用的模式。连接 OBS 适合直播和电脑录制；悬浮提词器适合直接使用手机原厂相机拍口播。

OBS 模式

让手机成为 OBS 摄像头。

提词只在手机上显示，不会进入 OBS 画面。

  1. 电脑安装软件

    安装 OBS Studio，再安装 DroidCam OBS 插件。安装完成后重启 OBS。

    OBS Studio 官方下载 ↗插件说明 ↗插件最新版 ↗
  2. 连接手机与电脑

    先让手机与电脑处于同一局域网；需要更稳定时可改用 USB。打开飞镜后保持推流页面在前台。

  3. 在 OBS 添加来源

    来源区域点击“+”，选择 DroidCam OBS，找到飞镜设备或填写手机显示的 IP 地址。需要手机声音时开启设备音频。

  4. 按现场调整

    可选择前后镜头、分辨率、帧率、码率、H.264/H.265 和音频。第一次建议保留默认值，画面稳定后再提高画质。

原厂相机模式 · 必做

开启“飞镜共享麦克风”。

Android 通常只允许一个应用占用麦克风。原厂相机开始录像后，飞镜需要通过这项无障碍服务共享声音，才能继续识别和滚动。

  1. 打开系统“设置”，进入“无障碍”。
  2. 在“已下载的服务”“更多服务”或“听觉辅助”里找到“飞镜共享麦克风”。不同品牌名称可能略有不同。
  3. 打开服务并确认授权，再回到飞镜切换“悬浮提词器”。
  4. 打开原厂相机录一小段，朗读一句，确认已读文字会变灰并自动向上移动。
这项服务只做什么？

只帮助飞镜在录像时继续取得麦克风声音。它不会读取屏幕内容、记录按键、代替你点击，也不会上传音频。

提词器

把文字放在最接近镜头的位置。

先让眼神自然，再调速度和显示。

  1. 粘贴或修改文稿

    在设置页进入“文字”，粘贴完整口播稿。返回后会立即刷新预览和提词内容。

  2. 调整阅读尺寸

    字号以不眯眼为准；悬浮模式可单独拖动高度，让下一句始终露出。需要反光板时再打开镜像。

  3. 选择滚动方式

    语音跟随适合自然口播：读到哪里，已读区域就会变灰并自动滚动。环境嘈杂或设备限制采音时，可暂时使用定速滚动。

  4. 选择显示模式

    OBS 录制用应用内提词器；原厂相机录像用悬浮提词器。两种模式共用同一份文稿和显示设置。

遇到问题，先看这里。

原厂相机录像后不再跟读

检查“飞镜共享麦克风”无障碍服务、麦克风权限和悬浮窗权限是否都已开启。部分 vivo、OPPO、小米设备还需允许后台运行并关闭飞镜的省电限制。

OBS 找不到手机

确认手机和电脑在同一局域网、插件已安装并重启 OBS；关闭隔离客户端的访客 Wi-Fi。使用 USB 时，确认系统已识别设备。

画面卡顿或延迟高

先降低分辨率、帧率或码率，优先使用 5 GHz Wi-Fi；直播环境建议用 USB 或稳定的局域网。编码可先选择兼容性更高的 H.264。

语音跟随跳过空行后看不到下一句

飞镜会把连续空行作为段落间隔处理，并在当前段落读完时提前露出下一段。仍觉得内容太少时，可直接拖高提词区域。

准备好了，就装到手机。

Android 6.0+；悬浮语音跟随建议 Android 10+。
